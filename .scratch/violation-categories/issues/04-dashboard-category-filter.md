# 04: ตัวกรองหมวดใน dashboard

**What to build:** staff กรอง dashboard ตามหมวดได้ เช่น ดูเฉพาะบ้านที่มีค่าปรับจอดรถค้าง ค่าเริ่มต้นคือ "ทั้งหมด" ตัวกรองนี้ทำงานร่วมกับตัวกรองสถานะและช่องค้นหาเดิม metrics และตารางบ้านคิดตามหมวดที่เลือก ดูรายละเอียดใน spec ที่ `.scratch/violation-categories/spec.md`

**Blocked by:** 02 (นับและเปิดรอบแยกตามหมวด)

**Status:** ready-for-agent

- [ ] dashboard มีตัวกรองหมวด ค่าเริ่มต้น "ทั้งหมด" รายการหมวดมาจาก API list หมวด
- [ ] metrics (บ้านที่มี violation, ค่าปรับค้าง, ยอดค้าง) คิดจาก `currentCycles` ที่ผ่านตัวกรองหมวด
- [ ] ตัวกรองสถานะ "ไม่มีรายการค้าง" หมายถึงไม่มีรอบ OPEN ในหมวดที่เลือก
- [ ] ถ้าเลือก "ทั้งหมด" ตารางบ้านแสดงยอดค้างรวมทุกหมวด
- [ ] selector test ครอบคลุมการรวมตัวกรองหมวด สถานะ และช่องค้นหา และมี component test ของ dashboard
