# Frontend stack

Vite + React 19 + TanStack Router (file-based, `src/routes/`). `vite build` emits a static SPA to `dist/`; there is no server runtime.

- `src/routeTree.gen.ts` is generated by the router plugin on `vite dev`/`vite build`. Commit it; never edit it by hand.
- Auth rules live in route `beforeLoad` (`src/routes/__root.tsx`, `_authenticated.tsx`, `login.tsx`, `change-password.tsx`, `_authenticated/users.tsx`), not in components.
- The API is same-origin `/api` (`VITE_API_URL` overrides it). `vite dev` proxies `/api` to `localhost:3001`.
- Tests render through a real router: `renderWithRouter()` for one component, `renderApp()` for the full route tree (`src/test/render.tsx`). Do not mock `@tanstack/react-router`.
